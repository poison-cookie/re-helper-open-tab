リンク開き方デバッグページ

同じように見えるリンクテキストを、通常遷移、別タブ、JavaScript、フォーム、アンカーなど複数パターンで配置しています。

通常のリンク

  • Example を開く 通常の <a href>。同じタブで遷移します。
  • Example を別タブで開く target="_blank"。ブラウザ設定により新しいタブまたはウィンドウ。
  • Example を安全に別タブで開く target="_blank" rel="noopener noreferrer"。
  • Example を名前付きタブで開く target="debug_named_tab"。同じ名前の閲覧コンテキストを再利用します。

特殊なリンク

  • ページ内の説明へ移動 ハッシュ付きのページ内アンカーです。
  • download 属性付きリンク download 属性付き。クロスオリジンでは通常ダウンロードにならない場合があります。
  • メール作成リンク mailto:。既定のメールクライアントを開きます。
  • 電話リンク tel:。端末やブラウザにより動作が変わります。

RE Open Tab 検出用リンク

  • PDF資料を開く URLに .pdf を含む通常リンクです。
  • 物件詳細を開く URLに /detail/ を含む通常リンクです。
  • 画像リンクを開く URLに .jpg を含む通常リンクです。初期設定ではOFF対象です。
  • JSでPDFを開く onclick 内の .pdf を検出し、補助ボタン追加を確認します。

JavaScript で開くリンク

  • JSで別タブを開く クリックイベントで window.open(url, "_blank") を実行します。
  • JSで同じタブを開く クリックイベントで window.location.href を変更します。
  • <button> をリンク風に見せ、クリックで開きます。
  • <form target="_blank"> による遷移です。

ページ内アンカーの到達先

ここは #anchor-target の移動先です。リンク検出や別タブ化処理が、ページ内リンクを外部リンクと同じように扱っていないか確認できます。
