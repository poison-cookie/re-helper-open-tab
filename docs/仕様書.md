# re-helper-open-tab 仕様書

## 1. 概要

不動産管理会社サイトや物件情報サイト上で、図面・PDF・物件詳細・画像などのリンクを確実に別タブで開けるようにするTampermonkeyスクリプトを作成する。

一部サイトでは、図面リンクが同じタブ名で開かれる、JavaScript経由で開かれる、クリックするたびに既存タブが上書きされる、といった問題がある。

本ツールでは、そうした挙動を補正し、複数の図面・物件詳細・PDFを並行して確認しやすくする。

---

## 2. プロジェクト名

リポジトリ名または機能名は以下を推奨する。

```text
re-helper-open-tab
```

Tampermonkey上の表示名は以下とする。

```text
RE Helper - Open Tab
```

日本語表示名は以下とする。

```text
不動産事務アシスト - 別タブ化
```

---

## 3. 目的

このスクリプトの目的は以下である。

```text
・図面リンクを別タブで開きやすくする
・PDFリンクを別タブで開きやすくする
・物件詳細リンクを別タブで開きやすくする
・同じ図面タブが上書きされる挙動を防ぐ
・JavaScriptリンクに「別タブで開く」ボタンを追加する
・サイトごとに有効/無効を切り替えられるようにする
```

---

## 4. 対象業務

主な利用場面は以下。

```text
・検索結果一覧から複数の物件詳細を開く
・複数の募集図面を並べて確認する
・図面PDFを別タブで確認する
・検索結果一覧を残したまま詳細画面を確認する
・同じ図面タブが上書きされるサイトで複数図面を開く
```

## 6. 初期機能一覧

### 6.1 サイト別ON/OFF

現在のホストごとに機能を有効化できるようにする。

初期状態では、現在サイトはOFFとする。
ユーザーがパネルまたはTampermonkeyメニューからONにした場合のみ動作する。

保存キー例：

```js
const SCRIPT_PREFIX = "reHelperOpenTab";
const ENABLED_HOSTS_KEY = `${SCRIPT_PREFIX}:enabledHosts`;
```

---

### 6.2 通常リンクの別タブ化

対象リンクと判断した `<a>` 要素に以下を付与する。

```html
target="_blank" rel="noopener noreferrer"
```

対象例：

```html
<a href="/zumen/123.pdf">図面</a>
<a href="/property/detail/123">詳細</a>
<a href="/files/room.pdf">PDF</a>
```

---

### 6.3 PDF・画像リンクの自動別タブ化

URLが以下の拡張子で終わる場合、リンクテキストに関係なく別タブ化する。

```text
.pdf
.jpg
.jpeg
.png
.webp
.gif
```

ただし、広告画像やアイコン画像へのリンクを誤検出しすぎる場合があるため、画像リンクの別タブ化は設定でON/OFFできるようにする。

---

### 6.4 図面・PDFっぽいJavaScriptリンクへの補助ボタン追加

以下のようなリンクやボタンは、通常の `target="_blank"` では対応できない。

```html
<a href="javascript:openZumen('123')">図面</a>
<button onclick="openPdf('456')">募集図面</button>
```

この場合、元のクリック処理は変更せず、横に小さな補助ボタンを追加する。

表示例：

```text
図面 [別タブ]
```

補助ボタンをクリックすると、可能な場合は元要素のclickを実行しつつ、`window.open` の上書き補正によって別タブ化する。

---

### 6.5 `window.open` の固定タブ名対策

一部サイトでは以下のように固定タブ名で開いている。

```js
window.open(url, "zumen");
window.open(url, "preview");
window.open(url, "pdf");
```

この場合、2回目以降のクリックで既存タブが上書きされる。

サイト別設定でONになっている場合、`window.open` をラップし、固定タブ名をユニークなタブ名に変換する。

例：

```js
const originalOpen = window.open;

window.open = function (url, target, features) {
  const newTarget = shouldForceUniqueWindowName(target)
    ? `re_helper_${Date.now()}_${Math.random().toString(36).slice(2)}`
    : target;

  return originalOpen.call(window, url, newTarget || "_blank", features);
};
```

ただし、全サイトで強制すると副作用があるため、初期状態ではOFFにする。
サイト別設定で明示的にONにした場合だけ有効化する。

---

### 6.6 補助ボタンの追加

対象要素が `<a>` でない場合、またはJavaScriptで開くタイプの場合、横に「別タブ」ボタンを追加する。

ボタン例：

```html
<button type="button" class="re-open-tab-button">別タブ</button>
```

クリック時の基本動作：

```text
1. 元要素のURLを抽出できる場合は window.open(url, uniqueTarget)
2. URL抽出できない場合は一時的に window.open を補正したうえで元要素.click() を実行
3. 失敗した場合は元要素.click() のみ実行
```

## 8. 判定ロジック

### 8.1 対象リンク判定

以下の関数を作成する。

```js
function shouldOpenInNewTab(element, settings) {
  // a/buttonなどを受け取り、別タブ化対象か判定する
}
```

判定に使う値：

```js
const text = element.textContent || "";
const href = element.getAttribute("href") || "";
const title = element.getAttribute("title") || "";
const ariaLabel = element.getAttribute("aria-label") || "";
const onclick = element.getAttribute("onclick") || "";
```

結合して判定用文字列を作る。

```js
const haystack = `${text} ${href} ${title} ${ariaLabel} ${onclick}`;
```

---

### 8.2 図面リンク判定

対象ワード：

```js
const DRAWING_KEYWORDS = [

  "募集図面",

  "販売図面",
```

### 8.3 PDFリンク判定

URLまたは文字列に以下がある場合。

```js

```

---

### 8.4 詳細リンク判定

対象ワード：


## 12. DOM変更監視

検索結果がAjaxで後から追加されるサイトに対応するため、`MutationObserver` を使う。

仕様：

```text
・childList / subtree を監視
・追加された要素だけ再処理
・100ms程度debounceする
・同じ要素を複数回処理しないようSetを使う
```

---

## 13. 二重処理防止

処理済み要素にはdata属性を付与する。

```html
data-re-helper-open-tab-processed="true"
```

別タブボタンを追加済みの要素にも印を付ける。

```html
data-re-helper-open-tab-button-added="true"
```

同じ要素に何度も `target="_blank"` を付けたり、ボタンを複数追加したりしないこと。

## 14. URL抽出

### 14.1 通常リンク

```js
function getElementUrl(element) {
  if (element.tagName === "A") {
    return element.href || element.getAttribute("href") || "";
  }

  return "";
}
```

### 14.2 onclickからのURL抽出

初期対応では、以下のような直接URLのみ抽出できればよい。

```js
openPdf("/pdf/123.pdf");
openZumen("/zumen/456");
window.open("/file/123.pdf", "zumen");
```

正規表現例：

```js
function extractUrlFromOnclick(onclick) {
  const match = onclick.match(
    /['"]([^'"]+\\.(?:pdf|jpg|jpeg|png|webp|gif)(?:\\?[^'"]*)?)['"]/i,
  );
  return match ? match[1] : "";
}
```

相対URLの場合は絶対URLに変換する。

```js
function toAbsoluteUrl(url) {
  try {
    return new URL(url, location.href).href;
  } catch (error) {
    return "";
  }
}
```

## 15. 別タブで開く処理

共通関数を作る。

```js
function openUrlInNewTab(url) {
  if (!url) {
    return false;
  }

  const uniqueTarget = `re_helper_${Date.now()}_${Math.random().toString(36).slice(2)}`;
  window.open(url, uniqueTarget, "noopener,noreferrer");
  return true;
}
```

## 16. `window.open` 補正

### 16.1 実装条件

以下の条件を満たす場合のみ有効にする。

```text
・現在サイトがON
・サイト別設定またはグローバル設定で forceWindowOpenUnique が true
```

### 16.2 注意点

一度だけ上書きすること。

```js
let windowOpenPatched = false;
```

```js
function patchWindowOpenIfNeeded(settings) {
  if (windowOpenPatched || !settings.forceWindowOpenUnique) {
    return;
  }

  const originalOpen = window.open;

  window.open = function (url, target, features) {
    const safeTarget = shouldRewriteWindowTarget(target)
      ? createUniqueTargetName()
      : target;

    return originalOpen.call(window, url, safeTarget || "_blank", features);
  };

  windowOpenPatched = true;
}
```

### 16.3 書き換え対象

以下のようなtargetはユニーク化する。

```text
zumen
preview
pdf
print
detail
window
sub
```

`_blank`、`_self`、`_top`、`_parent` は書き換えない。

## 21. 注意事項

### 21.1 ポップアップブロック

ブラウザはユーザー操作なしの複数タブオープンをブロックすることがある。
そのため、一括オープン機能は必ずボタンクリックなどのユーザー操作内で実行する。

### 21.2 サイト側仕様との衝突

`window.open` の上書きは副作用が出る可能性があるため、初期状態ではOFFにする。
必要なサイトだけONにする。

### 21.3 認証付きURL

ログイン済みサイトの図面URLは、別タブで開いてもログインセッションが必要な場合がある。
本ツールは認証を回避しない。
現在ログイン中のブラウザセッションで開ける範囲のみ対象とする。

### 21.4 画像/PDF内の文字認識はしない

本ツールはリンク挙動の補助であり、図面OCRは対象外とする。
